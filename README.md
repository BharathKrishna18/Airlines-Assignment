# Airlines Data Analysis Project

This project focuses on cleaning, validating, storing, and analyzing airline flight data.

## Workflow

```text
Excel Dataset
     ↓
Python / Pandas
     ↓
Data Cleaning & Quality Checks
     ↓
Cleaned CSV
     ↓
MySQL Database
     ↓
SQL KPI Analysis
     ↓
Power BI Dashboard
```
## Work Completed
-Loaded the airline dataset from Excel using Python and Pandas.
-Performed data cleaning and quality checks.
-Handled missing and invalid values.
-Checked and corrected data types and schema inconsistencies.
-Saved the cleaned dataset as a CSV file.
-Stored the cleaned flight data in MySQL.
-Performed KPI analysis using SQL.
-Connected the cleaned data to Power BI for dashboard creation.
-Technologies Used
-Python
-Pandas
-MySQL
-SQL
-Power BI

The project demonstrates a basic end-to-end data pipeline from raw flight data to cleaned data, database storage, analysis, and visualization.
